# 计算结果校验规则

## 1. 校验范围

第四阶段只校验上传文件中的计算结果，不把预算明细写入正式明细表，不做汇总入库。

## 2. 默认误差阈值

- 金额类：`0.01`
- 数量类：`0`
- 百分比类：`0.0001`

## 3. 销售额校验

规则：`预算销售额 = 预算销量 * 平均销售单价`。

系统从 `任务分解-数量` 读取产品编码、产品名称、平均销售单价和 1-12 月销量，从 `任务分解-金额` 读取上传销售额，按产品编码和月份比对。

## 4. 成本额校验

规则：`预算成本额 = 预算销量 * 成本价`。

系统从 `任务分解-数量` 读取销量，从 `任务分解-成本` 读取成本价和上传成本额。若成本价缺失，后续可从 `预算价格表` 读取补贴后价格或内部交易价格。

## 5. 费用校验

系统检查 `费用预算` 中 1-12 月金额是否为数字；有金额的行必须填写预算项目和预算小项。

## 6. 利润校验

规则：`预算利润 = 预算销售额 - 预算成本额 - 预算费用额`。

系统用重算销售额、成本额和费用额计算利润。如果 `利润分解表` 存在利润值，则按月份比对。销售额为 0 时，率类字段不能出现 `#DIV/0!`。

## 7. 合计校验

如果表中存在 `年度合计`、`全年合计`、`合计` 字段，则校验该列是否等于 1-12 月汇总。

## 8. 阻断逻辑

存在 `error` 时，上传文件状态更新为 `检查失败`，第五阶段不得直接入库。仅存在 `warning` 时，状态为 `检查警告`。
